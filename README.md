A modern, responsive, and bilingual digital menu for **Bunătățile Casei**, a catering business located in Comarnic, Romania. This site provides an easy way for customers to browse traditional and bio dishes, view daily specials, and place orders directly.

## ✨ Features

- **Bilingual Interface**: Full support for Romanian and English languages.
- **Dynamic Menu Generation**: Dishes and categories are dynamically rendered from a centralized data structure in JavaScript.
- **Responsive Design**: Optimized for mobile, tablet, and desktop viewing.
- **Smart Cart System**: Customers can select items and view their selection before ordering.
- **Ordering Integration**: One-tap phone call button for quick orders.
- **Service Rules Display**: Clear information about order timeframes for breakfast, lunch, and dinner.

## 🛠️ Technical Details

- **Frontend**: Vanilla HTML5, CSS3 (with Custom Properties for theming), and Modern JavaScript (ES6+).
- **Styling**: Custom CSS for a professional, restaurant-appropriate aesthetic.
- **Deployment**: Integrated with Netlify for continuous deployment and global hosting.

## 📁 Project Structure

- `index.html`: The main structural entry point.
- `style.css`: Custom styling, including a sticky navigation and responsive layouts.
- `script.js`: Contains the `menuData` object (the "database" of dishes) and the logic for rendering, language switching, and the cart system.
- `img/`: High-quality images for the menu items.
